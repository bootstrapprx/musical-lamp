# Handoff

Refatorada a interface de terminal para visão de servidores e custos (Cluster & FinOps) com navegação, painéis, abas de detalhes e janelas para adicionar/remover servidores, preservando operações e configurações existentes. Túnel Cloudflare ajustado para cloudflare/cloudflared:latest com execução via token; validação e dicas atualizadas. cargo check, cargo clippy e testes passaram.
